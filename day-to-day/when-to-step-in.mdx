description: "Quick-reference lookup: I see X, what do I do?"
---

A fast lookup for the recurring "what's the right move here?" moments. Each row links to the page with the full mechanics.

| Situation | Your action |
|---|---|
| Escalation in the Command Center | Resolve it. See [Resolving an Escalation](/day-to-day/escalations-playbook). |
| Disagree with a screening decision | Override on the [Screening tab](/recruiter/screening#overriding-a-decision). |
| Overriding the same kind of decision repeatedly | Stop overriding case-by-case — update [screening directives](/settings/screening). |
| Need to schedule a candidate by hand | Open the application → Details tab → **Schedule Interview**. |
| Candidate sent something the agent shouldn't answer | Send [operator guidance](/recruiter/communication#operator-guidance), or [dismiss the agent](/recruiter/communication#dismissing-the-agent) and take over. |
| Sensitive topic or candidate complaint | Dismiss the agent. Message directly. |
| Recruiter calendar is wrong | [Settings → Recruiters](/settings/recruiters); fix the underlying availability in Google Calendar. |
| Template wording is off | [Settings → Communication](/settings/communication). |
| Candidate keeps asking the same question the agent escalates on | Add the answer to [Knowledge Base](/settings/knowledge-base). |
| Repeat no-show escalation | Resolve the escalation — default recommendation is reject; override if you disagree. |
| Candidate replied but thread looks stuck | Check thread status on the [Communication tab](/recruiter/communication#thread-statuses). The agent may already be acting. |
| Candidate didn't reply for days | They're inside [follow-up policy](/recruiter/follow-up-policy) — check the cadence before nudging manually. |
| Interview finished | Mark **Interview Completed** or **No-Show** on the Details tab. |
| Salesforce record looks stale | Check [Salesforce writeback events](/integrations/salesforce#writeback-events) — Maigrate writes back on specific transitions, not continuously. |
