All candidate communication in Maigrate flows through **threads** — structured conversations that the communication agent manages. Recruiters can view every message, send direct messages, and give the agent private guidance.

## Two actions — don't confuse them

There are two ways a recruiter can intervene in a thread, and they do very different things:

| Action | Who sees it | What it does |
|---|---|---|
| **Direct message** | Candidate | Sent to the candidate over SMS or email. The agent sees that you sent it and adapts. |
| **Operator guidance** | Agent only | Private note. The agent treats it as authoritative on the next turn. The candidate never sees it. |

Pick the wrong one and either the candidate gets a message meant for the agent, or your guidance ends up in someone's inbox. The Communication tab keeps these in separate inputs — confirm the selector before sending.

## Viewing a thread

Open any application and click the **Communication** tab. The thread view shows:

- Every message sent to and received from the candidate, in chronological order
- The channel used for each message (SMS or email)
- Agent reasoning and decisions logged between messages
- Current thread status

## Channel routing

Maigrate chooses the outreach channel automatically:

| Condition | Channel |
|---|---|
| Valid mobile phone number | SMS via Twilio |
| Invalid phone or landline | Email via Resend |
| No phone on file | Email (or escalation if email is also missing) |

Candidates can opt out of SMS (replying STOP). Opt-outs are stored and respected on all future sends — SMS is removed from the candidate's viable channel set, so the agent will pick the next-best channel (typically email, if there's a valid email on file). If neither channel is available, the thread escalates.

## Sending a direct message

You can message a candidate directly from the Communication tab without going through the agent:

1. Type your message in the input box at the bottom
2. Select **SMS** or **Email**
3. Click **Send**

The message is delivered immediately via your configured Twilio or Resend account and logged in the thread. The agent sees the message in the thread history and factors it into its next action.

## Operator guidance

Operator guidance is a private instruction to the agent — the candidate never sees it. Use it to redirect the agent, provide context it doesn't have, or override its planned next step.

Examples:
- "Skip the next follow-up — I'm calling them directly"
- "This candidate needs weekend availability — offer Saturday slots"
- "Mark this thread as withdrawn, the candidate told me verbally they're no longer interested"

The agent treats operator guidance as authoritative. Write guidance in the same input area, but select **Operator guidance** before sending.

## Dismissing the agent

You can dismiss the communication agent from a thread if you want to take over manually. After dismissal, the thread is marked `human_owned` — no further automated messages will be sent. The **Dismiss Agent** button on the Details tab changes to a disabled **Agent Dismissed** indicator.

To hand the thread back to the agent, trigger a new scheduling flow (click **Schedule Interview** on the Details tab) — this re-opens a thread under agent control.

<Note>
  **When to dismiss vs guide.** Dismiss when the situation is sensitive, off-script, or needs extended back-and-forth the agent shouldn't be in (complex compensation, candidate complaints). Guide when the agent is mostly right but needs one constraint or fact ("Don't propose Friday slots, this recruiter is OOO"; "Confirm the rate of $X if asked").
</Note>

## Thread statuses

The thread carries a status that drives what (if anything) the agent does next. The values you'll see:

| Status | Meaning |
|---|---|
| `active` | Agent is actively driving the conversation |
| `waiting_on_external` | Outreach sent, waiting for a candidate reply |
| `waiting_on_domain` | Waiting on another internal step (e.g. screening) before continuing |
| `waiting_on_scheduling` | Waiting on the scheduling agent to act (e.g. propose slots, persist a booking) |
| `escalated` | The agent has surfaced an escalation; further automation is paused |
| `human_owned` | A recruiter dismissed the agent; no automated messages will be sent |
| `completed` | Workflow finished (interview booked and confirmed, candidate withdrew, etc.) |
| `cancelled` | Thread was cancelled |

A separate follow-up state tracks responsiveness: a candidate who never replies after the configured follow-up attempts gets marked `unresponsive`, and the application's scheduling status moves to `failed_outreach`.

## Message templates

The content of automated messages is configured in [Settings → Communication](/settings/communication). You can customize templates for:
- Initial scheduling outreach
- Follow-up nudges
- Interview confirmations
- Same-day reminders

The agent uses these templates as a starting point and may adapt the tone and content to the specific conversation context.
